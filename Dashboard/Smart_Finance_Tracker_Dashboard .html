Why Isolation Forest over Z-score: Z-score is univariate — it only checks amount. Isolation Forest uses 8 features simultaneously (amount, timing, category encoding, deviation from mean, percentile rank). A transaction can have a normal amount but be anomalous in timing or context — that's what this model catches.
